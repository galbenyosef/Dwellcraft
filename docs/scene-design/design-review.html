CREAM / COMPACT
01

奶油日光小家

一个紧凑、柔软、有生活感的三室两厅。让家具尺度服务于日常动线，让日光成为空间的主角。

100㎡游戏外轮廓
3室2厅一厨一卫
2.8m完成面层高

空间组织

西侧玄关连接公共过道，北侧三间卧室，南侧为客餐厨与阳台。卫生间直接连接过道；厨房面向餐厅。

材质与尺度

暖白墙面
浅橡木
亚麻织物
绿植点缀
  • 2.4m直排沙发，替代概念图中过大的转角沙发。
  • 四人餐桌、主卧1.8m床、次卧1.5m床、客卧1.2m床。
  • 浅阳台定位为采光与观景区，首套陈设不放桌椅。
设计审查 / REVIEW

已修正：卫生间从公共过道进入，避免正对餐桌。待白模验证：床侧净宽、餐椅退出与阳台可达范围。

NATURAL / OPEN
02

林景大平层

把客厅、餐厅和厨房组织成连续的生活空间，卧室留在安静的一侧。用原木、亚麻和林景形成自然层次。

200㎡游戏外轮廓
4室2厅一厨两卫
3.0m完成面层高

空间组织

北侧卧室与卫浴，南侧厨房、六人餐厅、客厅和景观阳台。公共卫浴设干区前室，主卫由主卧衣帽区进入。

材质与尺度

白垩墙面
原木
鼠尾草绿
炭灰细节
  • 3.2m组合沙发、1.8m六人餐桌、2m厨房岛台。
  • 岛台两侧预留约1.05m以上净通道，需在白模中实测。
  • 阳台采用窄花槽与靠边长凳，不摆两排休闲家具。
设计审查 / REVIEW

已修正：公共卫浴无需穿过洗衣区。待白模验证：餐厨动线、椅子拉出后的通行、长客厅家具分组。

LUXURY / LANDSCAPE
03

湖畔奢华庄园

一座可以真正进入的两层住宅，连接露台、泳池与花园。以石材和深木建立质感，让奢华来自尺度与细节。

4000㎡总场地面积
1000㎡两层建筑合计
12 × 5m独立室外泳池

空间组织

北侧进入，建筑居中偏北；南侧露台连接泳池，西侧草坪、东侧花园。楼下接待与活动，楼上家庭生活，五间卧室套房。

材质与尺度

浅石灰
深木饰面
香槟金属
湖蓝
  • 建筑基底25 × 20m，两层分别500㎡，不设挑空或第三层。
  • 主客厅、餐厅、影音室、健身房均具有独立空间。
  • 按楼层与区域加载；湖面、远山是场地之外的背景。
设计审查 / REVIEW

已修正：套房增加干区前室，阅读室与洗衣房通过东侧走廊独立进入；上下层楼梯占位一致。待白模验证：楼梯净空、户外碰撞与VR分区加载。

审查结果：布局成立，实测留给开发。

本轮已检查

  • 4个楼层占位总面积：100 / 200 / 500 / 500㎡。
  • 分区无重叠、无越界，所有房间通过开口可达。
  • 门洞位于相邻分区共同边界；上下层楼梯对齐。
  • 修正厨卫借道、套房入口和洗衣阅读空间的动线。
  • 概念图尺寸偏差已转为明确的建模修正要求。

后续必须实测

  • 家具摆放后的实际净宽与碰撞，门扇扫掠。
  • 楼梯踏步、层间标高、楼板开口和头部净空。
  • 实时材质、阴影、分区加载与浏览器帧率。
  • Quest 3／3S手柄操作、传送与VR舒适性。
  • 自定义GLB、存档恢复和跨设备作品包。

完整装修闭环

VR与自带模型

双手柄布置家具，校验GLB，处理VR资源，并打通电脑与头显之间的作品文件往返。
